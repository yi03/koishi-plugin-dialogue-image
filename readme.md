# Koishi Plugin - dialogue-image (图片问答)

[![npm](https://img.shields.io/npm/v/koishi-plugin-dialogue-image?style=flat-square)](https://www.npmjs.com/package/koishi-plugin-dialogue-image)

允许机器人识别用户发送的图片，并根据预设的规则进行回复，类似于 dialogue 插件，但专注于以 **图片** 作为触发条件（问题）。

## ✨ 功能特性

*   **图片作为问题**：核心功能，监听消息中的图片，匹配成功后触发回复。
*   **文本与图片混合回复**：回复内容可以是文本、Koishi 内置元素（如 at、表情）以及图片。
*   **多重回复与概率**：同一张问题图片可以设置多个不同的回复，并为每个回复指定触发概率。
*   **作用域控制**：支持设置全局问答或特定群组的问答。群组内优先匹配本群问答，无匹配时尝试匹配全局问答。
*   **本地图片存储**：将作为问题和回答的图片下载并存储在 Koishi 数据目录下的 `imgqa_images` 文件夹中，使用 `file://` 协议引用，提高稳定性和响应速度。
*   **灵活的回复语法**：支持在回复内容中使用特殊占位符：
    *   `$a`: @消息发送者
    *   `$s`: 消息发送者的昵称
    *   `$m`: @机器人自身
    *   `$n`: 将回复内容在此处分割，后续部分作为新消息发送。
    *   `$$`: 输出一个普通的 `$` 符号。
*   **管理命令**：提供添加、查看、删除、查询问题图片、清理本地缓存等管理功能。

## 📝 使用说明

### 基本逻辑

1.  当用户发送一条包含图片的消息时，插件会提取第一张图片。
2.  插件下载该图片，计算其内容的 MD5 哈希值。
3.  插件查询数据库，寻找与该哈希值匹配的问答条目：
    *   如果在群聊中，优先查找当前群组 (`guildId`) 的记录。
    *   如果本群没有匹配或在私聊中，则查找全局 (`guildId` 为空字符串) 的记录。
4.  如果找到一个或多个匹配的问答条目，插件会根据每个条目设置的 `probability`（概率）随机选择一个进行回复。
    *   如果所有匹配项概率总和大于 1，则会进行归一化后再抽取。
    *   如果概率为 0 或未选中任何项，则不回复。
5.  发送选中的回复内容，并处理其中的特殊语法（`$a`, `$s`, `$m`, `$n`, `$$`）。

### 📌 命令列表

**注意：** 大部分命令默认操作当前群组的问答。使用 `-g` 或 `--global` 选项可操作全局问答（通常需要更高权限）。

1.  **`imgqa.teach` (别名: `添加图片回复`, `imgadd`, `教图`)**
    *   **功能**: 添加或更新一个图片问答。
    *   **用法**: 回复一张你想作为 **问题** 的图片，然后输入此命令和 **回答** 内容。
    *   **语法**: `imgadd <回答内容> [-p 概率] [-g]`
    *   **选项**:
        *   `-p <0-1>`: 设置回复触发的概率，默认为 1.0 (100%)。若概率总和超过 1 将被标准化。
        *   `-g, --global`: 将此问答设为全局（需要权限 3）。
    *   **示例**: 回复一张猫猫图片，然后发送 `imgadd 这是猫猫！ -p 0.8`，即可添加一个看到这张猫图有 80% 概率回复“这是猫猫！”的问答。
    *   **回答内容**: 可以包含文本、@某人 (`$a`, `$m`)、发送者昵称 (`$s`)、分条发送 (`$n`)、普通美元符 (`$$`) 以及 **图片**。如果回答中包含图片，插件会自动下载并转为本地 `file://` 引用。
    *   **注意**: 如果对同一张问题图片，在同一作用域（本群或全局）添加了完全相同的回答内容，则会更新其概率；否则会添加为一条新的可能回复。

2.  **`imgqa.list` (别名: `图片回复列表`, `imglist`, `图列`)**
    *   **功能**: 查看已添加的图片问答列表。
    *   **语法**: `imglist [-p 页码] [-s 每页条数] [范围选项]`
    *   **选项**:
        *   `-p <页码>`: 指定查看的页码（从 1 开始），默认 1。
        *   `-s <条数>`: 指定每页显示的条目数量，默认 10。
        *   `-G, --global-only`: 仅显示全局问答。
        *   `--guild-only`: 仅显示本群问答（需在群内使用）。
        *   `-a, --all`: 查看所有范围的问答（需要权限 3）。
    *   **默认行为**: 在群聊中显示本群+全局问答，在私聊中仅显示全局问答。
    *   **输出**: 显示问答 ID、问题图片哈希前缀、作用域、概率和回答内容预览。

3.  **`imgqa.delete` (别名: `删除图片回复`, `imgdel`, `删图`)**
    *   **功能**: 删除指定 ID 的图片问答。可以一次删除多个，ID 之间用逗号 `,` 分隔。
    *   **语法**: `imgdel <ID1,ID2,...> [-g]`
    *   **选项**:
        *   `-g, --global`: 删除全局问答（需要权限 3）。
    *   **注意**: 默认只删除本群的问答。会检查 ID 是否存在于指定的作用域。

4.  **`imgqa.delete.all` (别名: `删除图片全部回复`, `imgdelall`, `删全图`, `清图`)**
    *   **功能**: 删除与指定图片哈希（或哈希前缀）相关的所有问答。
    *   **语法**: `imgdelall <哈希或前缀> [-g]`
    *   **选项**:
        *   `-g, --global`: 删除全局问答（需要权限 3）。
    *   **安全措施**:
        *   哈希前缀必须至少包含 `4` 个十六进制字符。
        *   如果提供的前缀匹配到 **多个不同** 的完整哈希值，操作会 **取消** 并提示用户，以防误删。只有当前缀能 **唯一确定** 一个完整哈希时，才会执行删除。
    *   **注意**: 默认只删除本群的问答。

5.  **`imgqa.query` (别名: `查询问答图片`, `imgget`, `查图`, `图ID`)**
    *   **功能**: 根据问答 ID 查询并显示其对应的 **问题** 图片。
    *   **语法**: `imgget <ID>`
    *   **查找范围**: 在群聊中会查找本群和全局，私聊中只查找全局。
    *   **输出**: 发送一条包含该问答信息（ID、范围、哈希前缀）和问题图片的消息。
    *   **前提**: 该问答记录必须包含有效的本地文件名信息（较新版本插件添加的记录会包含），且对应的图片文件必须存在于 `data/imgqa_images` 目录中。

6.  **`imgqa.clear` (别名: `清理图片缓存`, `imgclear`)**
    *   **功能**: 清理 `data/imgqa_images` 目录下未被任何问答记录（包括问题图片和回答中的图片）引用的本地图片文件。
    *   **语法**: `imgclear -y`
    *   **选项**:
        *   `-y, --confirm`: **必须** 添加此选项以确认执行。这是一个危险操作，会永久删除文件。
    *   **权限**: 需要权限 3。
    *   **注意**: 此操作不可逆，请谨慎使用。建议在执行前备份 `data/imgqa_images` 目录。

### 💡 核心概念

*   **作用域 (Scope)**: 每个问答记录都有一个 `guildId`。如果 `guildId` 是群号，则为该群专属；如果 `guildId` 是空字符串 (`''`)，则为全局问答。
*   **图片哈希 (Image Hash)**: 使用 MD5 算法计算图片内容的哈希值，作为图片的唯一标识符用于匹配。这意味着即使图片 URL 不同，只要内容完全一致，就会被视为同一个问题。
*   **本地存储 (Local Storage)**: 为了稳定性和避免依赖外部链接，插件会将教学时的问题图片和回答中引用的图片下载到 `koishi数据目录/data/imgqa_images/` 下，并以 `哈希值.扩展名` 命名。数据库和回复中会引用这些本地文件。`imgqa.clear` 命令用于清理不再被引用的本地文件。
*   **概率 (Probability)**: 当一张图片匹配到多个回答时，每个回答被选中的机会由其 `probability` 字段决定（0 到 1 之间的小数）。

### 🛡️ 权限

*   **默认权限 (Authority 1)**:
    *   `imgqa.teach` (添加/更新本群问答)
    *   `imgqa.list` (查看本群/全局问答)
    *   `imgqa.delete` (删除本群问答)
    *   `imgqa.delete.all` (删除本群问答)
    *   `imgqa.query` (查询问答图片)
*   **需要权限 3 (Authority 3)**:
    *   使用 `-g` 或 `--global` 选项进行全局问答的添加/删除 (`imgqa.teach`, `imgqa.delete`, `imgqa.delete.all`)。
    *   使用 `-a` 或 `--all` 选项查看所有范围的问答 (`imgqa.list`)。
    *   执行清理操作 `imgqa.clear`。
